Design of Embedded System with Wireless Interfaces for Strain Sensor Arrays

ISRO-sponsored project through RAC-S under Dr. Oppili Prasad L (June 2026). Developed an ESP32-based wireless sensor interface using ADC sampling with DMA and I2S for high-frequency data acquisition, followed by FFT-based signal processing and wireless data transmission. Extracted dominant frequency features and transmitted sensor measurements via Wi-Fi/HTTPS to Firebase for real-time monitoring.

Medical Diagnosis using Genetic Algorithm and Neural Networks

Applied a genetic algorithm (pop. size 20, crossover 0.4, mutation 0.055) for feature selection on 1,098 gastrointestinal bleeding WCE images using pre-trained CNNs (DenseNet, ResNet, InceptionV3). Ensemble model achieved 92% accuracy, outperforming individual models (74–76%, improved to 88–90% with data augmentation).
